# Assets

Place game assets here:

## sprites/
PNG sprite sheets for:
- `dino.png` – Dino running, jumping, ducking frames
- `cactus.png` – Small single, large single, and cluster variations
- `pterodactyl.png` – 2-frame wing-flap animation
- `ground.png` – Repeating ground texture strip
- `cloud.png` – Cloud sprite

## audio/
WAV audio files:
- `jump.wav` – Jump sound effect
- `die.wav` – Death / collision sound effect
- `score_milestone.wav` – Milestone score chirp (every 100 points)
